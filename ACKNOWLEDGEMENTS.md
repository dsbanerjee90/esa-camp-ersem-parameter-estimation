## Scientific software

This workflow builds upon the following modelling and data assimilation frameworks:

- **GOTM** — General Ocean Turbulence Model.
- **FABM** — Framework for Aquatic Biogeochemical Models.
- **ERSEM** — European Regional Seas Ecosystem Model.
- **EAT** — Ensemble and Assimilation Tool.
- **PDAF** — Parallel Data Assimilation Framework.

We acknowledge the respective developers and maintainers of these software frameworks.

In particular, we acknowledge Lars Nerger and collaborators at the Alfred Wegener Institute for developing and maintaining PDAF, which provides ensemble data assimilation functionality used by this workflow.
